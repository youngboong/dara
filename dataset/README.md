# Benchmark Dataset

## Precursor mixture dataset

This dataset contains XRD patterns (.xrdml files) for 20 different precursor mixtures.
Each precursor mixture is an equal weight combination of two or three different precursors. For
each mixture, two XRD scan is performed at different resolution (`2-min` fast scan and
`8-min` normal scan).

Each file has the following format:

```
precursor1_wt1-precursor2_wt2[-precursor3_wt3]--[2min|8min].xrdml
```

## Binary reaction dataset

This dataset contains XRD patterns (.xrdml files) for powder samples obtained from 20
binary (i.e., two precursor) reactions performed in the A-Lab. Each scan was performed
as 8-minute scans on the Malvern Panalytical AERIS X-ray diffractometer. The reactions
are all equi-cation, except for reactions with NH4H2PO4, which are equimolar.

Each file has the following format:

```
Xprecursor1-Yprecursor2_ZZZC_60min.xrdml
```

Where X and Y are the stoichiometric coefficients of the precursors, and ZZZ is the
temperature of the annealing hold time (60 mins) for all reactions.

## Ground truth

`dataset/ground_truth/` holds the reference answers used by the accuracy benchmark
(`scripts/run_benchmark.py`, package `dara.benchmark`):

- `pairwise_reactions.json` - the 20 binary-reaction products. Phases, space groups,
  lattice parameters, weight fractions and the sample displacement come from expert manual
  Rietveld refinements (`pairwise_reactions_manual_rietveld_summary.xlsx`) and the human
  assessments in `pairwise_reactions-benchmark_summary_102125.xlsx`.
- `precursor_mixture.json` - the 40 weighed mixtures (20 mixtures, 2-min and 8-min scans).
  The weighed masses in grams are encoded in the file names (`In2O3_0p3022` = 0.3022 g).

Conventions:

- Weight fractions are relative to the identified crystalline phases and sum to 100 wt%.
  For the precursor mixtures the weighed masses are renormalised: wt% = mass / sum(mass) x 100.
- Phase names in the spreadsheets are free text, so formulas were curated from the
  `Source_file` column. Structural families that a single model cannot distinguish carry
  `spacegroup: null` and an `accept_any_of` list (for example the Nb oxides and the Sr-Fe-O
  perovskites); polymorph or setting ambiguities carry `spacegroup_any_of`.
- Binary-reaction samples are scored in `elemental` mode with the elements of the precursors,
  as in the original workflow (`scripts/run_binary_reaction.py`).
- `allowed_extra` lists phases that are plausible but not weighed (for example Bi2CO5 in
  Bi2O3 + Li2CO3 mixtures); they are not counted as false positives. The alias `Li4CO5` maps to
  Li2CO3 (ICSD 181261 is Li2CO3 mislabelled).
- The files are generated by `scripts/convert_benchmark_xlsx.py --data-dir <folder with the
  spreadsheets>`; `--check` verifies that the committed JSON still matches. Do not edit the JSON
  by hand - change the `CURATED` table in the script and regenerate.
