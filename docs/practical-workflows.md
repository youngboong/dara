# 실무 분석 작업 흐름

기존 Results와 Visualize 조작을 유지하면서 다음 기능을 추가했습니다.

| 하고 싶은 작업 | 화면에서 사용하기 |
| --- | --- |
| 같은 시료로 조건을 바꿔 다시 분석 | 작업 상세 → **Copy conditions & rerun**. 저장된 패턴과 조건이 채워지며, 새 파일을 올리면 패턴만 교체됩니다. |
| 여러 시료 또는 온도별 패턴 비교 | Results에서 완료된 작업 2–20개 선택 → **Compare selected**. 정규화, 수직 오프셋, Overlay와 공통 2θ 범위를 조절합니다. |
| 후보에서 상을 빼거나 다른 참조상을 넣어 재정련 | 후보의 **Visualize result → Edit phases**. 체크된 CIF들만 함께 정련합니다. 다른 후보의 저장된 참조 CIF도 선택할 수 있습니다. |
| 홀더 피크 등 특정 구간을 제외 | Submit의 **Analysis range · 2θ**와 **Excluded intervals · 2θ**에서 시작/끝과 제외 구간을 입력합니다. 빈 시작/끝은 측정 범위를 사용합니다. |
| Rwp 최저값과 별도로 결과를 채택 | 작업 상세의 **Adopted result & lab notes**, 또는 후보의 **Adopt**. 메모를 입력하고 **Save review**로 저장합니다. |
| 보고서 저장 | **Report (saved choice)**는 채택 후보를, 미채택이면 최저-Rwp 결과를 내보냅니다. Visualize의 보고서 버튼은 현재 표시한 후보를 내보냅니다. |

## 결과 보존과 해석

- 조건 복사와 상 선택 재정련은 **새 작업**을 생성합니다. 원본 결과는 덮어쓰지 않습니다.
- 상 선택 재정련은 저장된 **참조 CIF**에서 다시 시작합니다. 기존 후보의 정련된 원자 좌표에서 이어서 실행하는 기능은 아닙니다. 원본 패턴·장비·파장·구간·최종 정련 설정을 이어받으며 데이터베이스 탐색은 반복하지 않습니다.
- 같은 상의 동등한 CIF 여러 개를 별도 성분으로 동시에 선택하지 마세요. 다른 다형을 함께 선택할 때도 회절과 시료 화학에 근거가 필요합니다.
- 제외 구간은 BGMN의 `CUT[n]`으로 적용합니다. 원본 측정 강도를 수정하지 않으며, 최종 피크 진단에서도 제외합니다. 회색 음영은 제외 구간입니다.
- 구간을 바꾸면 Rwp를 계산하는 데이터 자체가 달라지므로, 다른 구간의 Rwp를 그대로 우열 비교하면 안 됩니다.
- 패턴 비교의 정규화·오프셋·확대는 표시만 변경합니다. 다른 파장에서는 동일한 2θ가 동일한 d-spacing을 의미하지 않습니다.
- 채택은 실무자의 판단 기록이지, 후보를 과학적으로 검증했다는 자동 보증이 아닙니다. 정량값은 모델에 포함된 결정상 사이의 정규화된 질량분율이며, 미동정상·비정질 함량을 자동 포함하지 않습니다.

## 보고서와 파일

보고서는 인터넷 없이 열리는 HTML이며, 측정/분석 조건·Rwp·상별 정량값·보고된 격자상수와 불확도·차이 곡선을 포함한 피팅 그래프·COD/MP 참조·저장한 메모가 들어갑니다. 브라우저의 인쇄에서 PDF로 저장할 수 있습니다. 불확도가 없는 값은 임의로 만들어 표시하지 않습니다.

기존 전체/후보별 ZIP 다운로드는 그대로 사용할 수 있습니다. 저장하지 않은 메모가 있으면 보고서를 내보내기 전에 Save review를 누릅니다.

## 진행 상태·정련 조절·후보 비교 (추가)

- **작업 상세 → Stop analysis**: 대기 작업 취소, 실행 중인 해당 작업 프로세스와 하위 계산 프로세스 중단. 다른 작업은 건드리지 않습니다. 새 서버를 재시작한 후 실행한 작업부터 적용됩니다.
- 진행 단계는 작업 상세에서 자동 갱신됩니다. 후보 정련의 `n / N`은 후보 처리 수이며 전체 작업 시간의 백분율이 아닙니다. 검색/다운로드처럼 총량을 알 수 없는 단계에 가짜 진행률을 표시하지 않습니다.
- **Download completed candidates**: 최종 정련이 끝난 후보만 별도 ZIP으로 보존합니다. 진행 중이던 후보는 포함하지 않으며, 실행 순서 번호는 최종 Rwp 순위가 아닙니다. 체크포인트에는 정련 JSON과 작업 파일이 들어갑니다. 중단한 작업을 자동 재개하는 기능은 아닙니다.
- **Submit → Register instrument profile**: BGMN GEQ와 선택적 GER를 등록합니다. 프로파일 이름·광학계·방사선·검증자·표준시료/교정 메모를 기록합니다. 파일 등록만으로 교정되거나 적합성이 자동 검증되는 것은 아닙니다. 검증 표시는 실무자의 선언이고, 파일 해시와 등록 조건을 보존합니다. 기존 프로파일은 덮어쓰지 않습니다.
- **Submit / Edit phases → Final refinement controls**: 격자상수 고정/제한범위 정련, 우선배향 없음/구면조화함수 차수 2·4, 시료 피크폭 K1·K2·B1 정련/0 고정을 선택합니다. 미선택 항목은 저장된 조건을 유지합니다. 빠른 후보 검색 조건은 바꾸지 않으며, 명시한 최종 설정은 검색 단계의 개별 상 제한보다 우선합니다.
- **Results 상세 → Compare two candidate fits**: 후보 두 개의 상 조합 차이, 계산선, 잔차를 동일한 2θ 축에서 비교합니다. 차이가 큰 위치 버튼으로 확대할 수 있습니다. 후보가 하나면 버튼은 비활성화됩니다. 다른 측정점/관측 강도를 사용하는 결과는 직접 비교를 거부하며 제외 구간은 반영하지 않습니다.
- 배경함수 직접 편집, 개별 상별로 다른 정련 전략, 장비 프로파일의 자동 생성·표준시료 자동 검증은 이번 범위에 포함하지 않았습니다. 무리한 자유도 증가로 낮아진 Rwp를 신뢰도 점수로 표시하지 않습니다.

체크포인트와 등록 프로파일은 서버 MontyDB 경로의 상위 폴더 안 `task-checkpoints`, `instrument-profiles`에 저장됩니다. 서버가 제공하는 프로파일을 등록할 때는 신뢰할 수 있는 장비 파일만 사용하세요.

## 개발 검증

`scripts/smoke_worker_controls.py`는 별도 임시 DB에서 짧은 합성 작업을 실제 분리 프로세스로 실행하고 결과 저장·취소를 검증합니다. 외부 구조 DB 및 실제 회절 계산은 호출하지 않습니다.

`scripts/serve_workflow_qa.py`는 8899 포트에 합성 데이터만 사용하는 메모리 테스트 서버를 띄웁니다. 실제 사용자 DB나 분석 작업은 건드리지 않으며, 종료하면 시험용 변경은 사라집니다. `scripts/check_workflow_browser.mjs`는 이 서버에서 핵심 화면 흐름을 검증합니다. 합성 테스트 데이터의 정량값과 Rwp는 과학적 검증 결과가 아닙니다.
